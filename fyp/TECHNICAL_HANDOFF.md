For a presentation, explain that the detector supplies **candidate boxes**, the evidence step decides which candidates can affect a **rule-based exterior grade**, and the valuation step estimates a **conditional price range**, based on model, storage, grade and available market evidence. A model confidence score does not quantify crack severity. An empty prediction list cannot demonstrate that a phone is undamaged. The grade-A rule is provisional in that case and reflects the supplied images and current detector.

Keep the historical results separate from future experiments. ## Offline annotation exchange and source intake

The two practice packages are generated separately from the same hash-verified ten-image roster. They work without a server after download, store each actor's drafts separately, and can download and restore a JSON backup. The cloud importer verifies role, image ID and hash, validated boxes and distinct actor IDs and refuses to overwrite conflicting work. A private report distinguishes missing submissions, disposition disagreements, class differences, extent differences and unmatched boxes. Neither the offline nor online practice queues approve annotations.

Authorized COCO, YOLO and Pascal VOC imports preserve licence, authority, revision, upstream split and image hashes. They decode images before intake, reject invalid boxes and retain source annotations as independent, unverified reference files. Missing labels and empty source files remain distinct from reviewed negatives. The audit identifies duplicate candidates found in differently named upstream splits; verify the real phone and session manually.

The device-identification API now rejects malformed attachment payloads before provider calls and returns a structured manual-selection response when the provider reply cannot be interpreted. The shared upload parser also protects exterior analysis. The model, grade policy, pending valuation gate and draft pull request were kept separate from the dataset and offline tooling.

For report writing, use the [methodology and architecture outline](METHODOLOGY.md). The next milestone is agreement on the ten practice images followed by one consented, independently reviewed and device-disjoint holdout. The original historical benchmark can only be reproduced with its original image/label membership and settings.
