# Dataset sources and quality for the Colab experiment

The private-pool audit and grouped planner were rerun on 20 November 2026. The pool contained 95 registered front-display crops with zero independently approved annotations and zero verified device/session splits. Ten images are reserved for practice. No exact or near duplicates were flagged within this pool by the existing hash screen. Its 28 images with a short edge below 640 may lose thin-crack detail when resized. There were zero eligible new split assignments. No supervised smartphone training set or held-out research benchmark was produced.

| Source | Rights and access | Decision for this run |
| --- | --- | --- |
| Broken Interfaces, pinned Git revision `37877e61c93e17975a8a5968baefad3dba0b3231` | Dataset released under CC BY 4.0. Retain the authors, DOI, source revision, license and modification history. The optional intake fetches only the display-crop directory and verifies each file against Git. | 95 known display crops are available for independent review. The source SVG marks do not distinguish both target classes. Originals, crops and overlays share underlying captures. The checkerboard display study offers little evidence about back glass, camera glass or sides. |
| SSGD, source revision `2004178e4ff0cb61787e4940b871f1e5e2645c29` | Authors permit academic use of the dataset. The code has separate licensing. README reports 2,504 images, 3,914 defects and seven labels including crack and scratch. Tsinghua and Baidu archive requests returned cloud-proxy 403. | Strong candidate for front glass. Request a permitted archive. Inspect COCO categories, image quality and physical provenance. Separate ambiguous broken-glass and membrane examples. Its published fold configurations reuse validation as test. |
| Roboflow Mobile Damage Diagnosis | Cloud proxy 403. Version, image rights, redistribution terms, labels and split independence remain unverified. | Require an authorized versioned export and rights information before intake. |
| Open Images V4/V5 | The CVDF mirror documents generic object detection images and published dataset splits. Image-specific terms and smartphone damage annotations were not verified. | Excluded. An object box around a phone does not establish the location of damage or the absence of cracks. |

The GitHub Search API was also blocked by the proxy. No broad reuse permission was assumed from a public repository or a downloadable image. Back-glass, camera-glass, hairline-crack, scratch and varied-lighting coverage remain collection needs. A prospective, consented capture campaign after the original model release with a kept device/session register is a practical route to defensible independent test data. Document capture conditions and cloud-use permission privately.
